# SatisfactoryMods

Meine Sammlung eigener Mods und Experimente für **Satisfactory**.

Jede Mod erhält ein eigenes Verzeichnis. Entwicklungsstände sind nicht automatisch spielbereit.

## Mods

| Mod | Beschreibung | Status |
| --- | --- | --- |
| [WaterToggler](WaterToggler/README.md) | Temporärer Dry-Build-Modus: Wasser ausblenden und Schwimmen unterbinden | Konzept / Recherche |

## Grundsätze

- Eigenständige, voneinander getrennte Mods
- Keine dauerhaften Änderungen der Welt durch einen Runtime-Toggle
- Experimentelle Änderungen zuerst im Testsave prüfen
- Fremde Projekte als Referenz mit Quelle benennen; Code nicht ungeprüft übernehmen

## Entwicklung

Zielplattform ist Satisfactory mit Satisfactory Mod Loader (SML). Konkrete SML-, Spiel- und Toolchain-Versionen werden pro Mod nach einem Kompatibilitätstest festgelegt.
