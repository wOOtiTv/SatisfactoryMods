## Deutsch

Meine Sammlung eigener Mods und Experimente für **Satisfactory**.

Jede Mod erhält ein eigenes Verzeichnis mit einer zweisprachigen `README.md` (Deutsch/Englisch) und einer eigenen zweisprachigen `CHANGELOG.md`. Entwicklungsstände sind nicht automatisch spielbereit.

### Mods

| Mod | Beschreibung | Status | Änderungen |
| --- | --- | --- | --- |
| [WaterToggler](WaterToggler/README.md#deutsch) | Temporärer Dry-Build-Modus: Wasser ausblenden und Schwimmen unterbinden | Konzept / Recherche | [Changelog](WaterToggler/CHANGELOG.md#deutsch) |
| [wOOtiSwatches](wOOtiSwatches/README.md#deutsch) | Eigene, schlanke Farbpalette mit 27 Farben, ohne USS-Default-Ballast | Konzept / Entwicklungsvorbereitung | [Changelog](wOOtiSwatches/CHANGELOG.md#deutsch) |

### Grundsätze

- Eigenständige, voneinander getrennte Mods mit eigener Versionshistorie
- Keine dauerhaften Änderungen der Welt durch einen Runtime-Toggle
- Experimentelle Änderungen zuerst im Testsave prüfen
- Fremde Projekte als Referenz mit Quelle benennen; Code nicht ungeprüft übernehmen
- Änderungen pro Mod unter `Unreleased` dokumentieren; veröffentlichte Versionen mit Versionsnummer und Datum aufführen

### Entwicklung

Zielplattform ist Satisfactory mit Satisfactory Mod Loader (SML). Konkrete SML-, Spiel- und Toolchain-Versionen werden pro Mod nach einem Kompatibilitätstest festgelegt.

## English

My collection of custom mods and experiments for **Satisfactory**.

Each mod has its own directory with a bilingual `README.md` (German/English) and its own bilingual `CHANGELOG.md`. Development snapshots are not necessarily ready to play.

### Mods

| Mod | Description | Status | Changes |
| --- | --- | --- | --- |
| [WaterToggler](WaterToggler/README.md#english) | Temporary dry-build mode: hide water and disable swimming | Concept / research | [Changelog](WaterToggler/CHANGELOG.md#english) |
| [wOOtiSwatches](wOOtiSwatches/README.md#english) | Compact custom 27-color palette without USS default colors | Concept / development preparation | [Changelog](wOOtiSwatches/CHANGELOG.md#english) |

### Principles

- Independent, separate mods with their own version histories
- No permanent world changes through a runtime toggle
- Test experimental changes in a test save first
- Credit reference projects and review external code before adopting it
- Document changes per mod under `Unreleased`; list published versions with a version number and date

### Development

The target platform is Satisfactory with Satisfactory Mod Loader (SML). Specific SML, game and toolchain versions will be documented per mod after compatibility testing.
